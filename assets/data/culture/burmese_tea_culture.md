# ☕ မြန်မာ့လက်ဖက်ရည် ယဉ်ကျေးမှုနှင့် အရသာများ

> "အသားမှာ ဝက်၊ အသီးမှာ သရက်၊ အရွက်မှာ လက်ဖက်"

---

## 📌 လက်ဖက်ရည်ဆိုင်မှ အသုံးများသော အရသာအမည်များ

မြန်မာ့လက်ဖက်ရည်ဆိုင်များတွင် နို့ဆီ၊ နို့စိမ်းနှင့် လက်ဖက်ရည်ရည်ကျ (လက်ဖက်ရည်နှပ်ရည်) အချိုးအစားအပေါ် မူတည်၍ အမည်အမျိုးမျိုး ခေါ်ဆိုကြပါသည်။

| အမည် | ပါဝင်ပစ္စည်း အချိုးအစား | အရသာ ပုံစံ |
| :--- | :--- | :--- |
| **ကျစိ (ကျခါးစိမ့်)** | လက်ဖက်ရည်ကျ + နို့စိမ်းများများ + နို့ဆီနည်းနည်း | ဖန်ခါးပြီး စိမ့်သောအနံ့ရှိသည် |
| **ချိုစိမ့်** | နို့ဆီ + နို့စိမ်း မျှတစွာ ပါဝင်သည် | အချိုနှင့် အစိမ့် မျှတသည် |
| **ချိုပြစ်** | နို့ဆီ အဓိက ပိုထည့်ထားသည် | အလွန် ချိုပြစ်သည် |
| **ပေါက်စီ / ချိုပေါက်** | နို့ဆီ ပိုပြီး ရေနွေးအနည်းငယ် ပိုသည် | ချိုပြီး သောက်ရလွယ်သည် |
| **ကျချို** | လက်ဖက်ရည်ကျ ပိုထည့်ထားသည် | ခါးချို အရသာရှိသည် |
| **ကျဲစိ** | နို့စိမ်း ပိုပြီး ရေနွေးဆူဆူ ပါဝင်သည် | အရသာ ပါးပါးစိမ့်စိမ့် ဖြစ်သည် |

---

## 📝 လက်ဖက်ရည်ကောင်းတစ်ခွက် ဖြစ်စေရန် အချက်များ

- [x] **လက်ဖက်ခြောက်:** အရည်အသွေးကောင်းမွန်သော လက်ဖက်ခြောက်ကို သုံးရပါမည်။
- [x] **ရေနွေးဆူချိန်:** ရေနွေးသည် တကယ် ဆူပွက်နေရပါမည်။
- [ ] **နှပ်ချိန်:** လက်ဖက်ခြောက်ကို ရေနွေးထဲတွင် အရောင်နှင့် အနံ့ထွက်သည်အထိ အချိန်မှန် နှပ်ထားရပါမည်။
- [ ] **အချိုးအစား:** မိမိနှစ်သက်သော ချို၊ စိမ့်၊ ခါး အချိုးအစားအတိုင်း သမအောင် မွှေရပါမည်။

---

## 💡 သိကောင်းစရာ

မြန်မာနိုင်ငံတွင် လက်ဖက်ရည်ဆိုင်များသည် သောက်စရာ ရောင်းချသည့်နေရာ သက်သက်မဟုတ်ဘဲ၊ မိတ်ဆွေများ ဆုံစည်းရာ၊ စကားစမြည် ပြောဆိုရာနှင့် လူမှုရေး၊ စီးပွားရေး ဆွေးနွေးရာ **လူမှုအသိုင်းအဝိုင်း ဗဟိုချက်** တစ်ခုလည်း ဖြစ်ပါသည်။
